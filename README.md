#### 🧭 [code-context-engine](https://github.com/ParsaVictor/code-context-engine) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/code-context-engine?style=social) ![Release](https://img.shields.io/github/v/release/ParsaVictor/code-context-engine?color=F90001&label=release)
MCP context engine for AI coding agents — a local code graph answers *"which files does this task need?"*. **Recall 1.000** on repos it was never tuned on, **45% fewer context tokens** in a real Claude Code session.<br>
`Rust` `MCP` `tree-sitter` `local-first`

#### 🔥 [FireGuard — fire & smoke detection](https://github.com/ParsaVictor/FireGuuard_Fire_detection_smoke) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/FireGuuard_Fire_detection_smoke?style=social)
Real-time fire and smoke detection for indoor CCTV with hazard-state alerting and instant email alarms — dataset audit → training → TensorRT export → live inference.<br>
`YOLO` `TensorRT` `OpenCV`

#### 🏴‍☠️ [Concealed Face Detection](https://github.com/ParsaVictor/thief-face-detection) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/thief-face-detection?style=social)
Tells a robber in a balaclava from a customer in a surgical mask, in real time — pose-based orientation, occlusion-hardened tracking, zero training.<br>
`InsightFace` `Pose` `Tracking`

#### 🪧 [PelakX — license plate recognition](https://github.com/ParsaVictor/pelakx-license-plate-detection) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/pelakx-license-plate-detection?style=social)
Open-source multilingual ALPR: vehicle + plate detection, Persian & Latin OCR, per-country plate grammar validation and temporal fusion. Iranian plates out of the box.<br>
`YOLO` `OCR` `Temporal fusion`

#### ⛑️ [PPE Sentinel](https://github.com/ParsaVictor/PPE_detection-Sentinel) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/PPE_detection-Sentinel?style=social)
PPE compliance monitoring for construction CCTV — person-grounded two-stage pipeline with ByteTrack, geometric head/torso association and temporal hysteresis.<br>
`YOLO` `ByteTrack` `TensorRT FP16`

#### 🧠 [Visual Intelligence Engine](https://github.com/ParsaVictor/visual-intelligence-engine) · ![Stars](https://img.shields.io/github/stars/ParsaVictor/visual-intelligence-engine?style=social)
Multimodal search over an image archive — face recognition, species and food recognition, and open-vocabulary text search on one unified index.<br>
`CLIP` `InsightFace` `SQLite`

#### 🔬 [PCB Component Classifier](https://github.com/ParsaVictor/pcb-component-classifier) · [Detection — YOLOv8](https://github.com/ParsaVictor/pcb-component-detection-yolov8)
Explainable Random Forest over 33 hand-engineered CV features (**93.3% holdout**, every prediction traceable), plus a YOLOv8 baseline on **675k real annotations**.<br>
`scikit-learn` `YOLOv8` `OpenCV`

#### 📈 [3D Point Cloud Curve Reconstruction](https://github.com/ParsaVictor/point-cloud-curve-reconstruction)
Benchmark of **5 peer-reviewed algorithms** for denoising and curve reconstruction on industrial 3D-printing scans — 43 tests, CI green.<br>
`PCA` `Clustering` `Least-squares`
